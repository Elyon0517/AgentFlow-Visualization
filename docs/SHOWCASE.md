# Reproduce the showcase

Verified locally on 2026-10-24 with Python 3.12 / Node 24 as applicable and Chromium headless.
Commands run from the repository root. Browser screenshots use synthetic example data.

## Commands

```bash
pnpm install --frozen-lockfile
pnpm test
pnpm build
pnpm exec tsc --noEmit
pnpm exec playwright install chromium
pnpm test:e2e
```

## What was verified

- 104 unit tests passed; production build and TypeScript check passed.
- Browser E2E passed: finish the 50-event bundled simulation, verify the terminal UI state,
  switch to timing and telemetry, export a trace, parse its events and reimport it.
- `assets/screenshots/` contains browser captures of topology, timing and telemetry.
- This also regresses a real bug: a terminal event received inside the React commit throttle
  could leave the UI at `running`. A pending commit now survives until the next refresh.
- Input is the bundled synthetic workflow. No live SSE server or trading service was tested.

## Reading the images

Screenshots are committed so GitHub renders them immediately. They are generated by the
browser acceptance scripts, not hand-composed mockups. Re-running a capture can change
layout, animation timing and measured latency slightly. Browser traces on test failure
are local debugging artifacts and are not committed.
